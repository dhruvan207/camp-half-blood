# Quellen und Lizenzen

Alle verwendeten fremden Dateien stehen unter der freien Lizenz **CC0** (gemeinfrei).
Alles andere (Gelände, Gebäude, Hütten, Bäume, Wasser, Feuer, Figuren) ist selbst im Code gebaut.
Weißer Marmor, Ares-Farbe, Wasserwellen, Gras-Büschel und Gesichter sind selbst gezeichnet (im Code).
Es werden keine Bilder aus den Filmen, kein Buchcover und keine fremden Fan-Art-Modelle verwendet.
